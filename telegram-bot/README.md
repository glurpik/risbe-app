# Telegram AI-бот на DeepSeek

Готовый к запуску Telegram-бот: DeepSeek под капотом, бесплатный лимит сообщений,
дальше — платная подписка через встроенные Telegram Stars (без внешнего
платёжного шлюза, банковских счетов и юрлица).

## Что нужно, чтобы включить

1. **Токен бота** — напиши [@BotFather](https://t.me/BotFather) в Telegram,
   `/newbot`, придумай имя и юзернейм. Это отдельная сущность бота,
   не твой личный аккаунт.
2. **Ключ DeepSeek API** — https://platform.deepseek.com, раздел API keys.
3. Скопируй `.env.example` в `.env` и впиши оба значения.
4. `npm run tg:start` (или `node telegram-bot/bot.js`) из корня проекта.

## Монетизация

`/buy` шлёт инвойс в Telegram Stars (валюта `XTR`) — своя внутренняя валюта
Telegram, комиссии и вывод регулируются самим Telegram, юрлицо не требуется
для приёма. Цена и период подписки — в `bot.js` (`prices`, `setSubscribed`).

## Что стоит донастроить перед реальным запуском

- **Ниша/персона бота** (`BOT_PERSONA` в `.env`) — общий ассистент почти
  ничем не лучше бесплатного ChatGPT-бота, конкретная узкая польза
  (резюме, разбор кода, конкретный язык/предмет) продаётся лучше.
- **Хранение истории** сейчас в памяти процесса — при перезапуске обнуляется.
  Для продакшена перенести в БД.
- **Модерация** — сейчас бот отвечает на любой текст без фильтрации, для
  публичного запуска стоит добавить базовые ограничения (long context abuse,
  запрещённый контент и т.п.).
- Реальных денег/платежей эта ночь не трогала — всё готово, но не запущено.
